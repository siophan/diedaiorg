# 迭代盛典 · 官方网站（含完整后台 CMS）

## 项目概述
- **名称**：迭代盛典-影视专业毕业生作品颁奖盛典 官方网站
- **目标**：品牌展示、毕业生报名、作品征集，所有前台内容都能在后台编辑
- **视觉**：沿用官方 PDF 的「深空蓝星空 + 立体蓝色五角星 + 香槟金细线框」，Logo 从 PDF 原图抠出透明底版本

## 前台页面
| 路径 | 说明 |
|---|---|
| `/` | 首页：主视觉、截止倒计时、数据亮点、参赛通道、关于、活动亮点、获奖作品、扶持计划、新闻、历届、发起人、院校 Logo 滚动墙、图库 |
| `/about` | 盛典介绍、主体运营、产业生态、发展历程、组织架构、传播矩阵 |
| `/news`、`/news/:id` | 新闻动态（分类：盛典动态 / 公众号文章 / 媒体报道 / 通知公告） |
| `/editions`、`/editions/:year` | 历届盛典（2021 / 2024 / 2025 / 2026） |
| `/works` | 获奖作品海报墙（24 部）+ 24 项奖项设置 |
| `/experts` | 发起人与专家评审 |
| `/partners` | 合作院校 / 机构 / 主承办 / 支持单位 Logo 墙 |
| `/gallery` | 图库，按相册分类，带灯箱 |
| `/rules` | 作品征集规则 + 奖项 |
| `/register` | **报名入口**（按届次开放） |
| `/submit` | **作品提交入口**（按届次开放：海报上传、网盘链接；每所院校限 10 部） |
| `/query` | 报名 / 作品审核进度查询（编号 + 手机号） |
| `/contact` | 商务合作留言 |

## 后台 `/admin`
- 默认账号：`admin` / `Diedai@2026`（**上线前请立即修改**）
- 仪表盘：报名、作品、留言统计，各院校提交数
- 内容管理：新闻（富文本编辑器，支持粘贴/上传图片）、历届盛典（控制报名/提交开关与截止日期）、获奖作品、人物、合作院校、图库
- **公众号一键导入**：粘贴 mp.weixin.qq.com 链接，自动抓取标题、正文、封面、日期，图片转存到 R2，绕开微信防盗链
- 报名与作品：搜索筛选、审核状态、批量操作、评审意见（参赛者可在前台查到）、CSV 导出
- 站点设置：首页主视觉、关于、数据、亮点、扶持计划、生态、规则、奖项、时间线、组织架构、页尾等 13 个模块，表单从 JSON 自动生成
- 媒体库（R2）、账号管理（超级管理员 / 编辑）、修改密码

## 数据架构
- **Cloudflare D1**：settings、editions、works、people、partners、news、gallery、registrations、submissions、messages、media、admins、sessions
- **Cloudflare R2**：后台和参赛者上传的图片，通过 `/media/*` 访问
- 认证：PBKDF2 密码哈希 + HttpOnly 会话 Cookie
- 初始内容：`scripts/build_seed.py` 生成 `seed.sql`

## 内容来源
- PDF 招商手册：Logo、星空背景、24 张获奖海报、9 位评审照片、40+ 张活动照片、规则、奖项、组织架构、扶持计划
- 创办人介绍文档：盛典定位、主体公司、产业生态
- 公众号「迭代盛典」：搜狗微信搜索只检索到 3 篇文章，已录入并配上封面
- 公开报道：新华网、文汇报、上戏、搜狐/南方周刊
- 院校 Logo 来自各院校官网标识，缺少 Logo 的单位自动显示金色文字徽标

## 本地开发
```bash
npm run build
npm run db:migrate:local && npm run db:seed
pm2 start ecosystem.config.cjs   # http://localhost:3000
```

## 部署
- 平台：Cloudflare Pages + D1 + R2（**尚未部署到生产环境**）
- 部署前需要创建 D1 数据库并把 `wrangler.jsonc` 里的 `database_id` 换成真实值；创建 R2 bucket `webapp-media`；然后执行远程迁移和种子数据
